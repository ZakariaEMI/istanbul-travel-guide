# Istanbul Atlas V4 — no API key build

This variant uses the standard OpenStreetMap tile layer instead of CARTO. No map API key is required.

Upload index.html, style.css, data.js and app.js to the root of your GitHub Pages repository. The standard OpenStreetMap tile server has a usage policy: https://operations.osmfoundation.org/policies/tiles/ . This service is best for modest traffic and does not guarantee availability. For larger public use, select a suitable commercial/hosted tile provider.

The map will be light instead of dark. Both tour and destination detail maps use the same provider.
